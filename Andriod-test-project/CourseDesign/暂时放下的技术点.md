> ## Activity栈的工作原理
>
> Android使用**Activity栈（Task Stack）**来管理Activity的生命周期：
>
> ```java
> // 每次调用startActivity()都会将新Activity压入栈顶
> startActivity(intent); // ActivityA -> ActivityB
> startActivity(intent); // ActivityA -> ActivityB -> ActivityC
> ```
>
> ## 潜在问题
>
> ### 1. **Activity堆叠问题**
> ```java
> // 问题示例：重复启动同一Activity
> private void goToLogin() {
>     Intent intent = new Intent(this, LoginActivity.class);
>     startActivity(intent); // 没有finish()，旧Activity还在栈中
> }
> ```
>
> ### 2. **内存泄漏风险**
> 每个Activity都占用内存，不合理的栈管理会导致内存消耗过大。
>
> ## 解决方案
>
> ### 1. **使用finish()关闭当前Activity**
> ```java
> Intent intent = new Intent(this, MainActivity.class);
> startActivity(intent);
> finish(); // 关闭当前Activity，防止堆叠
> ```
>
> ### 2. **使用Intent标志位**
> ```java
> Intent intent = new Intent(this, MainActivity.class);
> // 清除栈中所有Activity，创建新任务
> intent.setFlags(Intent.FLAG_ACTIVITY_NEW_TASK | Intent.FLAG_ACTIVITY_CLEAR_TASK);
> startActivity(intent);
> ```
>
> ### 3. **单例模式启动**
> ```java
> Intent intent = new Intent(this, MainActivity.class);
> // 如果Activity已存在，清除其上所有Activity
> intent.setFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP);
> startActivity(intent);
> ```
>
> ## 针对你的登录场景
>
> ```java
> // 登录成功后的推荐做法
> private void goToMainActivity() {

>         // 登录成功后通常不希望用户返回登录页

> GitHub Copilot: 关于 `setFlags()` 中的这两个参数，让我详细解释一下：
>
> ## Intent.FLAG_ACTIVITY_NEW_TASK
> - **作用**：在新的任务栈中启动 Activity
> - **场景**：通常用于从非 Activity 上下文（如 Service、BroadcastReceiver）启动 Activity
> - **效果**：创建一个新的任务栈来承载目标 Activity
>
> ## Intent.FLAG_ACTIVITY_CLEAR_TASK
> - **作用**：清除目标 Activity 所在任务栈中的所有其他 Activity
> - **前提**：必须与 `FLAG_ACTIVITY_NEW_TASK` 一起使用
> - **效果**：目标 Activity 成为任务栈中的唯一 Activity
>
> ## 组合使用的效果
>
> ```java
> intent.setFlags(Intent.FLAG_ACTIVITY_NEW_TASK | Intent.FLAG_ACTIVITY_CLEAR_TASK);
> ```
>
> 这个组合的作用是：
> 1. **清空当前任务栈**：移除栈中所有现有的 Activity
> 2. **启动新的根 Activity**：目标 Activity 成为新任务栈的根节点
> 3. **防止返回**：用户按返回键时会直接退出应用或回到桌面
>

> ## Fragment是什么？
>
> **Fragment**是Android中的一个重要组件，可以理解为"页面片段"或"子页面"：
>
> ```java
> // Fragment基本结构
> public class HomeFragment extends Fragment {
>     @Override
>     public View onCreateView(LayoutInflater inflater, ViewGroup container,
>                              Bundle savedInstanceState) {
>         // 加载Fragment的布局
>         return inflater.inflate(R.layout.fragment_home, container, false);
>     }
> }
> ```
>
> ## Fragment vs Activity的区别
>
> - **Activity**: 完整的页面，有自己的生命周期
> - **Fragment**: 页面的一部分，必须依附在Activity中
>
> ## 如何实现分开显示？
>
> ### 1. 在Activity中使用多个Fragment
>
> ```java
> public class MainActivity extends AppCompatActivity {
>     @Override
>     protected void onCreate(Bundle savedInstanceState) {
>         super.onCreate(savedInstanceState);
>         setContentView(R.layout.activity_main);
>         
>         // 显示登录用户的主页Fragment
>         if (userIsLoggedIn()) {
>             loadFragment(new UserHomeFragment());
>         } else {
>             // 显示游客状态的Fragment
>             loadFragment(new GuestHomeFragment());
>         }
>     }
>     
>     private void loadFragment(Fragment fragment) {
>         FragmentTransaction transaction = getSupportFragmentManager().beginTransaction();
>         transaction.replace(R.id.fragment_container, fragment);
>         transaction.commit();
>     }
> }
> ```
>

>

>     android:layout_height="match_parent">
>     
>     <!-- Fragment容器 -->
>     <FrameLayout
>         android:id="@+id/fragment_container"
>         android:layout_width="match_parent"
>         android:layout_height="match_parent" />
>         
> </LinearLayout>
> ```
