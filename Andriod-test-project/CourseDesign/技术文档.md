### 学习资源获取总览

*   **官方文档永远是第一选择：**
    *   **Android Developers 官网 (developer.android.com):** 这是学习安卓开发最权威、最全面的地方。它有详细的指南 (Guides)、参考 (Reference)、示例代码 (Samples) 和最佳实践 (Best Practices)。对于Room、ViewModel、LiveData、ViewPager2等Jetpack组件，官方文档都有专门的教程。
    *   **Java SE 官方文档 (Oracle/OpenJDK):** 对于Java语言基础和核心库，Oracle的官方文档和OpenJDK的文档是权威来源。
*   **知名在线学习平台：**
    *   **Google Codelabs (codelabs.developers.google.com):** 提供很多手把手的安卓和Java编程练习。
    *   **Udacity (优达学城):** Google官方合作推出了很多安卓开发纳米学位课程，质量很高，但部分可能收费。可以找找他们免费的入门课程。
    *   **Coursera / edX:** 一些大学会在这上面提供Java和安卓开发的课程。
    *   **YouTube:** 有大量免费的编程教程，但需要筛选质量。寻找订阅量高、评价好的频道。
    *   **B站 (bilibili.com):** 国内也有很多优秀的编程UP主分享Java和安卓学习视频。
*   **开发者社区和博客：**
    *   **Stack Overflow:** 遇到具体问题时，这里几乎总能找到答案或思路。
    *   **Medium / CSDN / 掘金 / InfoQ:** 有很多开发者分享的技术文章和教程。

### 各阶段推荐教程及学习方向

下面针对之前技术文档中提到的开发阶段，给出具体的学习资源建议：

---

**阶段一：环境搭建与基础模型 (Room数据库基础)**

*   **核心技术：** Android Studio环境熟悉、Gradle依赖管理、Room基础 (Entity, DAO, Database)。
*   **推荐资源：**
    1.  **Android Studio 安装与配置：**
        *   **官方文档：** 在 `developer.android.com` 搜索 "Install Android Studio"。
        *   **关键词：** "Android Studio setup tutorial", "安卓Studio安装教程"。
    2.  **Room Persistence Library 官方指南：**
        *   **官方文档：** `developer.android.com` -> "Data and storage" -> "Room persistence library"。这里有关于如何添加依赖、定义实体、DAO和数据库类的完整教程。
        *   **Google Codelabs:** 搜索 "Android Room with a View - Java" (这是一个经典的Room入门Codelab，虽然官方示例可能优先Kotlin，但Java版本通常也有或者很容易找到对应思路)。
        *   **关键词：** "Android Room tutorial Java", "安卓Room数据库入门教程 Java", "Room Entity DAO Database Java"。
    3.  **SQLite 基础 (可选，有助于理解Room底层)：**
        *   **W3Schools / Tutorialspoint:** 搜索 "SQL tutorial", "SQLite tutorial"。了解基本的SQL语句如 `CREATE TABLE`, `INSERT`, `SELECT`。
*   **学习目标：** 理解Room的基本组件和注解，能够创建一个简单的数据库表，并进行基本的插入和查询操作。

---

**阶段二：用户注册与登录 (基础版 - Activity, SharedPreferences)**

*   **核心技术：** Android `Activity` 生命周期、XML布局、`EditText`、`Button`、`Intent` 跳转、`SharedPreferences`。
*   **推荐资源：**
    1.  **Activity 官方指南：**
        *   **官方文档：** `developer.android.com` -> "App fundamentals" -> "Activities"。重点理解Activity的生命周期 (Lifecycle) 和如何启动Activity (`startActivity`)。
        *   **关键词：** "Android Activity tutorial Java", "安卓Activity生命周期", "Android Intent Java"。
    2.  **Layouts (布局) 官方指南：**
        *   **官方文档：** `developer.android.com` -> "User interface" -> "Layouts"。学习 `LinearLayout`, `RelativeLayout`, `ConstraintLayout` (推荐)。
        *   **关键词：** "Android XML layout tutorial", "安卓ConstraintLayout教程"。
    3.  **UI Controls (控件) 官方指南：**
        *   **官方文档：** `developer.android.com` -> "User interface" -> "UI controls"。查找 `EditText`, `Button` 的用法。
        *   **关键词：** "Android EditText tutorial", "Android Button onClick Java"。
    4.  **SharedPreferences 官方指南：**
        *   **官方文档：** `developer.android.com` -> "Data and storage" -> "Save key-value data" (SharedPreferences)。
        *   **关键词：** "Android SharedPreferences tutorial Java", "安卓SharedPreferences用法"。
*   **学习目标：** 能够创建简单的UI界面，处理用户输入和按钮点击，实现页面跳转，并使用SharedPreferences存储简单数据。

---

**阶段三：密码安全与会话强化 (PBKDF2)**

*   **核心技术：** Java加密库 (`javax.crypto`)、PBKDF2算法原理、安全随机数生成 (Salt)。
*   **推荐资源：**
    1.  **Java Cryptography Architecture (JCA) 参考指南：**
        *   **官方文档 (Oracle/OpenJDK):** 搜索 "Java Cryptography Architecture (JCA) Reference Guide"，特别是关于 `SecretKeyFactory` 和 `PBEKeySpec` (用于PBKDF2) 的部分。
        *   **关键词：** "Java PBKDF2 example", "Java password hashing PBKDF2 salt", "安卓密码加密 PBKDF2"。
    2.  **Bouncy Castle (可选，更全的加密库)：**
        *   如果需要更广泛的加密算法支持，可以了解Bouncy Castle库。但对于PBKDF2，Java内置库通常足够。
    3.  **安全博客和文章：**
        *   搜索 "password hashing best practices", "why salt passwords"。理解为什么需要哈希和加盐。
        *   **OWASP (Open Web Application Security Project) 网站：** 有很多关于Web和应用安全的优秀资源，包括密码存储指南。
*   **学习目标：** 理解密码哈希和加盐的重要性，能够使用Java库实现PBKDF2对密码进行安全处理。

---

**阶段四：管理员内容管理 (RecyclerView, ViewModel基础)**

*   **核心技术：** `RecyclerView` 和 `Adapter`、`ViewModel` 基础。
*   **推荐资源：**
    1.  **RecyclerView 官方指南：**
        *   **官方文档：** `developer.android.com` -> "User interface" -> "Lists and grids" -> "Create dynamic lists with RecyclerView"。
        *   **Google Codelabs:** 通常会有结合RecyclerView的Codelab。
        *   **关键词：** "Android RecyclerView tutorial Java", "安卓RecyclerView Adapter Java"。
    2.  **ViewModel 官方指南：**
        *   **官方文档：** `developer.android.com` -> "App architecture" -> "Architecture components" -> "ViewModel"。
        *   **Google Codelabs:** 搜索 "Android ViewModel Codelab Java"。
        *   **关键词：** "Android ViewModel tutorial Java", "安卓ViewModel用法"。
*   **学习目标：** 能够使用RecyclerView展示列表数据，理解ViewModel的作用并用其管理UI数据。

---

**阶段五：图片处理与展示集成 (文件IO, Intent, 图片加载)**

*   **核心技术：** Android文件系统 (内部/外部存储)、`Intent` (用于图片选择)、`ContentResolver`、`Bitmap` 处理基础。
*   **推荐资源：**
    1.  **Data and file storage overview 官方指南：**
        *   **官方文档：** `developer.android.com` -> "Data and storage"。了解应用专属存储 (App-specific storage)。
        *   **关键词：** "Android internal storage Java", "安卓外部存储私有目录"。
    2.  **Getting content from the user (图片选择) 官方指南：**
        *   **官方文档：** `developer.android.com` -> "User interface" -> "Sharing content" -> "Getting content from the user" (或者搜索 "Android pick image from gallery Intent Java")。重点学习使用 `ActivityResultLauncher`。
        *   **关键词：** "Android pick image gallery Java ActivityResultLauncher", "安卓选择图片教程"。
    3.  **Loading large bitmaps efficiently 官方指南：**
        *   **官方文档：** `developer.android.com` -> "Performance" -> "Media performance" -> "Loading large bitmaps efficiently"。了解直接加载大图可能导致的问题和优化方法。
        *   **关键词：** "Android load bitmap efficiently Java", "安卓加载图片优化"。
    4.  **(可选，但推荐了解) 图片加载库 Glide / Picasso：**
        *   **GitHub项目主页及Wiki：** 搜索 "Glide GitHub" 或 "Picasso GitHub"。它们能极大简化图片加载、缓存和显示的复杂性。虽然本项目建议你手动实现以学习，但了解这些库对未来有益。
        *   **关键词：** "Glide tutorial Android Java", "Picasso tutorial Android Java"。
*   **学习目标：** 能够让用户从设备选择图片，将图片保存到应用存储，并能根据路径加载显示图片。

---

**阶段六：普通用户浏览功能 (ViewPager2, Fragment)**

*   **核心技术：** `Fragment` 生命周期与通信、`ViewPager2` 和 `FragmentStateAdapter`。
*   **推荐资源：**
    1.  **Fragments 官方指南：**
        *   **官方文档：** `developer.android.com` -> "App fundamentals" -> "Fragments"。
        *   **Google Codelabs:** 搜索 "Android Fragments Codelab Java"。
        *   **关键词：** "Android Fragment tutorial Java", "安卓Fragment生命周期"。
    2.  **ViewPager2 官方指南：**
        *   **官方文档：** `developer.android.com` -> "User interface" -> "Layouts" -> "Create swipe views with ViewPager2"。
        *   **关键词：** "Android ViewPager2 FragmentStateAdapter Java tutorial", "安卓ViewPager2教程"。
*   **学习目标：** 能够使用ViewPager2配合Fragment实现滑动翻页效果。

---

**阶段七：角色区分与UI完善 (LiveData, 综合应用)**

*   **核心技术：** `LiveData` (用于数据观察和UI自动更新)、条件逻辑、UI/UX基础。
*   **推荐资源：**
    1.  **LiveData 官方指南：**
        *   **官方文档：** `developer.android.com` -> "App architecture" -> "Architecture components" -> "LiveData"。
        *   **Google Codelabs:** 通常在ViewModel或Room的Codelab中会结合LiveData使用。
        *   **关键词：** "Android LiveData tutorial Java", "安卓LiveData ViewModel Room"。
    2.  **Material Design 指南 (material.io/design):**
        *   虽然不直接是编码教程，但了解Material Design的设计原则有助于你做出更美观、用户体验更好的界面。
*   **学习目标：** 能够使用LiveData将数据变化从ViewModel传递到UI，实现UI的响应式更新，并完成应用的整体逻辑和界面优化。
