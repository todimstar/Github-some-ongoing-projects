**项目概况:**
*   **项目名称:** 知识科普App (练手项目)
*   **平台:** 安卓 (Android)
*   **核心功能:**
    *   允许管理员动态管理科普知识条目（包含图片和文字描述）。
    *   普通用户可以注册、登录、滑动翻页浏览科普内容，并修改自己的密码。
*   **用户角色:**
    *   **管理员 (Administrator):** 账户内定，负责内容的增删改。
    *   **普通用户 (Regular User):** 需要注册登录，主要进行内容浏览。
*   详细描述：主题，实现一个知识科普app，科普内容包括若干种（编程概念科普）的图片和简介，可滑动翻页。要求：系统分两个用户角色：管理员和普通用户。 功能说明：（1）管理员可以添加、修改、删除（编程概念科普）数据（即：app中展示的知识数据是动态的可变的，不是固定死的）；（2）普通用户可以浏览科普页面；（3）管理员账户可系统内定，普通用户可以自己注册账户，进入app时需要验证登录，未注册用户（或用户名、密码错误）无法登录，普通用户可修改自己的密码。

**已确定的技术选型与方案:**
*   **编程语言:** Java
*   **数据库:** SQLite，通过 **Room Persistence Library (Room持久性库)** 进行交互。
*   **UI组件:** 将使用标准的安卓UI组件，包括 `Activity` (活动)、`Fragment` (片段)、`ViewPager2` (用于实现滑动翻页效果)、`RecyclerView` (可能用于管理员界面的列表展示)。
*   **密码安全:** 采用 **PBKDF2 (基于密码的密钥派生函数2)** 算法，并结合 **加盐 (Salting)** 的方式存储用户密码。
*   **会话管理 (Session Management):** 使用安卓的 `SharedPreferences` (共享偏好) 来记住用户的登录状态。
*   **图片处理:** 管理员从设备选择图片后，图片将被复制到应用的 **私有存储空间 (Internal/External Private Storage)**，数据库中仅存储图片的 **文件路径 (File Path)**。
*   **推荐架构组件:** 建议使用 `ViewModel` (视图模型) 和 `LiveData` (实时数据) 来构建更健壮的应用架构。
